# Home-Credit-AI-Assignment.


## Project Overview
An AI voice agent built using Dograh for the preliminary qualification of customers interested in a Loan Against Property (LAP).

## Agent Details
- **Agent Name:** Sakshi
- **Company:** Home Credit
- **Language:** English
- **Purpose:** Collect customer eligibility details and determine whether they meet the preliminary criteria.

## Eligibility Checks
1. Property type
2. Ownership status
3. Original property document availability
4. Requested loan amount
5. Occupation and income source
6. Estimated property market value
7. Loan tenure

## Technologies / Platform
- Dograh AI
- AI voice agent
- Text-to-Speech (TTS)

## Project Files
- Workflow configuration
- System prompt
- Test conversation transcript
- Test call recording (if included)

## Important Note
This agent performs preliminary qualification only. It does not approve or sanction loans.
